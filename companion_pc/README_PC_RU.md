# Помощник подписи на ПК — 1.3.0-rc1

## Установка исходной версии

Нужен Windows с работающей КЭП, КриптоПро CSP и зарегистрированным компонентом КриптоПро ЭЦП (CAdESCOM), а также Python 3.11 или новее. Сертификат с доступным закрытым ключом должен быть установлен у текущего пользователя Windows в «Личное». Полномочия сертификата должны позволять работу с выбранным ИНН в ЧЗ. При работе сотрудника нужна корректная МЧД и права в системе; помощник их не выдаёт.

Распаковать папку в обычное место, например `C:\CHZ_SetCollector`. Не запускать прямо из ZIP. Открыть `Start_PC.cmd` двойным щелчком. Первый запуск создаёт локальное Python-окружение `.venv` и устанавливает зависимости из `requirements.txt`; для этого нужен интернет. Обычный запуск не требует прав администратора.

Скрипт открывает браузер с локальной панелью. Не закрывать консоль во время работы. Для остановки нажать Ctrl+C в консоли, когда отправка завершена. Программа не устанавливает службу или автозапуск Windows.

Если в этой же папке есть собранный `CHZ_PC_Helper.exe`, Start_PC.cmd запускает его; отдельный Python тогда не нужен. EXE в исходном комплекте отсутствует, способ сборки описан ниже.

## Подключение ТСД

Панель подписи доступна только на самом ПК: `http://127.0.0.1:18766/` с секретом в начальной ссылке из консоли. По голому адресу без секрета данные не открываются.

Приёмник ТСД работает по `https://локальный_IP:18765`. Только частные адреса 10.*, 172.16–31.* или 192.168.*. По сети доступны передача набора и чтение его статуса, но НЕ подписание, вход в ЧЗ, отмена или отправка в ЧЗ.

На странице нажать «Показать подключение / QR», выбрать сетевой адрес ПК, отсканировать QR через меню подключения Android. Проверить адрес и SHA-256 на обоих устройствах. Используется шифрованное соединение с проверкой конкретного сертификата помощника; защита TLS глобально не отключается.

QR подключения не является кодом маркировки. Он содержит секрет доступа к очереди и не должен попасть в публичный скриншот. Программа не размещает этот QR на внешнем сервисе. При необходимости адрес/ключ/отпечаток можно ввести вручную.

Если QR показывает не тот адрес из нескольких сетевых карт, выбрать другой в списке. Можно запустить `Start_PC.cmd --advertise 192.168.1.10`, подставив действительный локальный IP. При изменении IP ПК переподключить ТСД; желательно закрепить IP на роутере.

Если мешает брандмауэр, `Firewall_PRIVATE.cmd` после отдельного подтверждения открывает TCP 18765 только для частной сети и локальной подсети. Этот скрипт запускается от администратора отдельно. НЕ открывать порт 18766 в сеть, не настраивать проброс портов роутера и не отключать весь брандмауэр.

## Подпись

Выбрать действующий сертификат, отметить наборы одного ИНН и контура, проверить состав и подтвердить кнопку «Подписать и отправить выбранные в ЧЗ».

Помощник запрашивает случайную строку ЧЗ и подписывает её для входа, затем подписывает каждый документ формирования набора откреплённой подписью CAdES-BES. Подписываются точные байты JSON UTF-8. Подпись проверяется компонентом CAdESCOM перед передачей серверу.

Закрытый ключ и PIN не читаются Python-кодом и не экспортируются. Окно PIN вызывает криптопровайдер. Его собственные настройки кеширования PIN остаются вне управления помощником.

Нажатие «Проверить выбранные в ЧЗ» может потребовать входа по КЭП, но не повторяет отправку документа формирования. Автоматическое чтение статусов после отправки использует уже полученную сессию и не вызывает новую подпись.

## Данные

По умолчанию: `%LOCALAPPDATA%\CHZSetCollector`.

- `queue.sqlite3`, `queue.sqlite3-wal`, `queue.sqlite3-shm` — очередь/журнал. Не удалять рабочие файлы.
- `connection.json` — ключ подключения ТСД, порты.
- `tls.crt`, `tls.key` — сертификат и ключ шифрования соединения помощника. Это НЕ КЭП ЧЗ.
- `backup-*.sqlite3` — согласованные резервные копии очереди, созданные кнопкой.

Не копировать только queue.sqlite3 во время работы: последние записи могут быть в WAL. Использовать кнопку резервного копирования. Для восстановления остановить помощник, сохранить исходную папку целиком и восстанавливать согласованную копию со специалистом. Не удалять очередь для обхода запрета повторной отправки.

## Ошибки

«Набор должен быть Нанесён»: проверить отчёт о нанесении в СУЗ, не заказывать замену автоматически.

«Пачка уже вложена в другой агрегат»: выяснить текущее состояние агрегации. Эта версия не делает разагрегацию сама.

CAdESCOM не зарегистрирован: установить/восстановить компонент КриптоПро ЭЦП подходящей разрядности; помощник запускает стандартный PowerShell Windows. Одного CSP может быть недостаточно.

Сертификат не найден: проверить установку в Личное текущего пользователя, носитель, срок и доступность закрытого ключа.

401/403 от ЧЗ: проверить права, ИНН, сертификат/МЧД и контур. Не менять токены вручную на Android: там они не используются.

«Результат неизвестен»: не повторять POST и не создавать новый локальный набор из тех же кодов. Нажать проверку, сверить документы в ЛК ЧЗ. При неизвестном результате помощник намеренно не считает операцию ни успешной, ни безопасной для повтора.

## Сборка EXE на Windows

Из корня проекта сначала выполнить тесты:

```bat
py -3 -m pip install -r companion_pc\requirements.txt
py -3 -m unittest discover -s tests -v
cd companion_pc
py -3 -m pip install pyinstaller==6.22.3
py -3 -m PyInstaller --clean --noconfirm --onefile --name CHZ_PC_Helper --hidden-import qrcode.image.svg --collect-all cryptography --add-data "web:web" --add-data "signer.ps1:." server.py
```

Файл появится в `dist`. К нему приложить Start_PC.cmd, Firewall_PRIVATE.cmd и этот README. Сборка EXE и проверка КЭП на Windows в текущей среде НЕ выполнялись.
