Наборы на подпись

Получение набора с ТСД не отправляет его в ЧЗ. Подпись и отправка — только по вашей кнопке.

Помощник перезапущен. Откройте новую панель по ссылке из окна Start_PC.cmd. Эта панель использует старый ключ; очередь сохранена.

1. Подключить ТСД

ПК и ТСД должны находиться в одной локальной сети. Ключ ЧЗ на ТСД не нужен.

Выберите адрес ПК, доступный с ТСД:

На ТСД нажмите «Подключить ПК» и отсканируйте этот QR. Проверьте совпадение адреса на обоих устройствах.

Данные для ручного ввода
QR содержит секрет подключения. Не публикуйте его и не отправляйте посторонним.


2. Выбрать подпись
Подключите носитель УКЭП. Нужны КриптоПро CSP и установленный компонент КриптоПро ЭЦП (CAdESCOM). PIN вводится только в окне КриптоПро.


3. Проверить и отправить
Production — реальный учёт ЧЗ. Выбранные наборы одного ИНН, контура и товарной группы отправляются одним документом. Проверьте состав перед подписью.
Проверка в ЧЗ
Обновление списка показывает сохранённую очередь ПК. Для чтения ЧЗ после запуска помощника нужен один вход по УКЭП.
Проверить общий документ выбранных наборов


Где хранятся данные
Очередь сохраняется на диске ПК и на ТСД. При неизвестном результате отправки автоматического повтора не будет. Ошибки сохраняются отдельно от статуса «Сформирован».
