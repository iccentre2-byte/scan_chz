# Проверки версии 1.3.0-rc1

Дата: 11.10.2026. Основа — архив пользователя scan_chz-main.zip, версия 1.2.4.

## Выполнено

**42 Python-теста — PASS.** Команда: `python -m unittest discover -s tests -v`.

Тесты проверяют структуру SETS_AGGREGATION, точные подписываемые байты, непустую подпись, ОСУ со сторонним владельцем вложения, принадлежность кода набора, состав GTIN, защиту от неполных/повторных кодов, сохранение/восстановление SQLite, резервное копирование, отсутствие повторного POST после таймаута, восстановление фактического результата, запрет удалённой подписи, секрет локальной панели, защиту от чужого Origin/Host и реальную HTTP/TLS-передачу между локальными тестовыми клиентами и сервером.

Тесты API ЧЗ и подписанта используют имитации. Реальная TLS-передача проверялась только внутри этой машины с тестовым сертификатом помощника. Искусственная подпись тестов никогда не попадает в рабочий запуск программы.

**24 JVM-проверки реального Domain.kt — PASS.** Kotlin-модуль компилировался локально и выполнялся: GTIN, ИНН, нормализация, символы внутри серийного номера, GS-разделитель, ограничения состава, независимость очередей. Это не проверка всего APK.

Добавлены также 11 JUnit-тестов для запуска Android workflow, включая ограничения адреса помощника. Их Gradle-запуск здесь НЕ выполнялся.

**Синтаксис JavaScript — PASS:** `node --check companion_pc/web/app.js`.

**XML — PASS:** разметка и манифест разбираются; все используемые MainActivity поля ViewBinding присутствуют в activity_main.xml.

## Не выполнено / среда блокирует

1. Полная сборка Android: нет SDK. Gradle wrapper не смог загрузить Gradle 8.2: `java.net.UnknownHostException: services.gradle.org`. Проверка доступности репозитория Android также завершилась ошибкой разрешения имени. Новый APK не получен.
2. Windows EXE: не собирался; здесь Linux. Подготовлен workflow Windows и команда PyInstaller, но их успешность на Windows не заявляется.
3. CAdESCOM, носитель КЭП, окно PIN и подпись пользователя: не запускались. Закрытый ключ пользователя не предоставлялся.
4. Реальные авторизация, чтение кодов и документ в ЧЗ: не выполнялись. Нужен контрольный запуск на одном реальном наборе или правильно подготовленных кодах тестового контура.
5. Сканер M3 SL20, реальное Android-устройство и установка APK: не проверялись.
6. Полный браузерный сценарий локальной панели: окружение Chromium заблокировало переход к локальному серверу (`ERR_BLOCKED_BY_ADMINISTRATOR`). Дополнительная попытка автономного рендеринга не дала подтверждённого результата. Успешная визуальная/runtime-проверка UI не заявляется. API панели отдельно покрыто тестами HTTP/TLS.

## Первый контрольный запуск

Не удалять 1.2.4. Собрать пилот с отдельным package id, запустить помощник, сканировать QR подключения и заполнить профиль/состав. Выбрать один из пяти существующих пустых кодов набора в правильном статусе. Собрать фактические пачки, передать на ПК. Убедиться, что без кнопки отправки документ в ЧЗ не создаётся. Проверить состав, выбрать сертификат и подтвердить отправку. Сверить документ и вложения в ЧЗ. Только после этого расширять использование.

Не следует считать прохождение локальных тестов гарантией юридической корректности прихода, прав владельца, допуска ОСУ-кодов или принятия реального документа ЧЗ.
